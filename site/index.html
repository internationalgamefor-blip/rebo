How it works

Install. pip install -r requirements.txt from the repo.
Add your key. export ANTHROPIC_API_KEY="sk-ant-..." from the Claude Console.
Pack your video. rebo pack --topic "..." --niche "..." — get the full package in seconds.
Publish. Copy the Markdown straight into YouTube Studio. Done.
